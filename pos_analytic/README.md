# POS Analytic Account (Odoo 19)

Adds an **Analytic Account** setting to each Point of Sale
(*Point of Sale > Configuration > Settings > Accounting*).

Every accounting entry generated by that POS carries the analytic account:

| Flow | Entry |
|------|-------|
| Session closing | Closing journal entry (sales, taxes, rounding, COGS, balancing line) |
| Session closing | Bank payments (`account.payment`) and their closing differences |
| Session closing | Cash statement lines and cash difference entries |
| Session | Cash in / cash out statement lines |
| Order invoicing | Customer invoice / refund, invoice payment entries, closing-entry reversal |
| Order / session | Stock valuation entries created by POS pickings |

By default only profit & loss journal items (income, expense, COGS) are tagged so
analytic reports stay meaningful. Turn on **Balance sheet lines** to also tag
receivable, cash, bank and stock valuation lines.

An existing analytic distribution on another plan (for example from a linked
sale order) is kept and the POS account is added next to it. An existing
distribution on the same plan is left untouched.
